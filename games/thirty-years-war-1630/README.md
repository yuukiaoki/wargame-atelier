# 三十年戦争 1630–32 ― スウェーデン参戦

グスタフ・アドルフのドイツ遠征（1630–32年）を作戦級ヘックスで描くウォーゲーム試作です。ルールの詳細は [RULEBOOK.md](RULEBOOK.md) を参照してください。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（静的サイト、サーバ不要）。開始画面で指揮する軍（スウェーデン軍／皇帝・カトリック同盟軍）を選び、相手はAIが指揮します。タップ／クリック優先のUIで、スマホでもプレイできます。

## システムの要点

- 軍は「リーダー＋戦力ポイント（SP）」のスタック。移動力は軍ごとに **1d6＋指揮能力** で決まる（『フリードリヒ大王』式）。
- シークエンスは **移動 → 非フェイズ側の強行軍（反応移動）→ 戦闘（同一ヘックス）**。敵が自分のヘックスに入ってきても、強行軍で離脱できる。野戦を強要したければ、相手のターンに敵のヘックスへ踏み込む必要がある。
- 戦闘は両軍の実効戦力比による **自前CRT** で解決し、損害は自軍SP基準のパーセントで受ける。リーダーの戦死チェックがあり、別リーダーが「弾除け」になることもある。グスタフ・アドルフが戦死すればサドンデス敗北。
- 要塞・都市には守備隊がいる。**強襲** のほか **包囲**（ターン経過で陥落判定）も可能。陥落した都市を占領すると、自軍から1SPを割いて守備隊を置く。
- **補給**：支配都市が補給源。6ヘックスを超えて離れた軍は損耗の恐れ。冬季ターン（第4四半期）は移動力低下と冬季損耗がある。
- イベント：マクデブルクの略奪（皇帝側VP-5とザクセン参戦の引き金）、ザクセン参戦（アルニム）、ベルンハルトとガラスの登場、ヴァレンシュタイン復帰、ティリーの致命傷（1632年）。
- 勝利条件：10ターン終了時の VP（支配都市の点数 − 累積損害）比較。ほか、グスタフ・アドルフ戦死・野戦軍壊滅による即時決着。

## 設計ノート

### 典拠と抽象化

- 史実の骨格（上陸の時期と場所、各将軍の動向、マクデブルク陥落とザクセン参戦の因果、ヴァレンシュタインの復帰とリュッツェン）は一般的な三十年戦争史の事実関係に基づきます。翻訳文そのものは含みません。
- マップはドイツ全域を 22×15 ヘックスに様式化したもので、都市位置・河川は概略です。1ヘックスは概ね 40–50km 相当を想定しています。
- 軍のSP・指揮能力・CRTの数値はすべてゲーム用に自前で設定した抽象化であり、史実の兵力比の厳密な再現ではありません。1SPは数千人規模の野戦軍の抽象とお考えください。
- マクデブルクは、皇帝軍に抵抗したプロテスタント都市としてスウェーデン側支配で開始します（守備隊のみ）。陥落時の略奪イベントで史実の惨事とその政治的帰結（ザクセン参戦）を表します。

### ルールの由来と自前設計の範囲

- 「リーダーごとにダイス＋指揮能力で移動力を決める」「非フェイズ側の強行軍を挟むシークエンス」「同一ヘックス戦闘」「攻城・補給・冬季損耗」といった **仕組みの発想** は、SPI『フリードリヒ大王』(1975) をはじめとする作戦級ウォーゲームのジャンルの慣行に学んでいます。仕組み（アイデア）自体は先行作の模倣ではなく、このジャンル共通の語彙です。
- CRT の数値表、戦力値、指揮能力、イベント処理、VP計算などの **具体的な数値と実装はすべて本作独自の設計** であり、先行作の表やデータを転写したものではありません。
- 効果音エンジン（js/sound.js）は本リポジトリ第1作「桶狭間 1560」のものを再利用しています（Web Audio による手続き的合成、外部素材なし）。

### 既知の制限（試作版）

- バランスは試作段階です。ヘッドレス検証（AI対AI 40戦）では皇帝側がやや有利（スウェーデン側の勝率約2割）でした。皇帝側の内線と初期VPの厚みが効いています。人間がスウェーデン側を集中運用すればAIドライバより好成績のはずですが、追加の調整は今後の課題です。
- AIは作戦級の簡易なもの（目標都市への進軍、要塞防衛、主力の集中、無謀な戦闘の回避）で、読みの深さはありません。
- 実機（スマホ）での見た目・操作感は未確認です。カウンターの文字は小さめです。
- 対人対戦（ホットシート／オンライン）は未実装です。
