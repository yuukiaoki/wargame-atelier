# 宰相 — 第1部（1633–44）ルールブック

本書は `games/oxenstierna/` の実装済みルールをそのまま記述したものです。数値・表はすべてゲーム本体（js/scenario.js、js/game.js）からの転記です。

## 1. ゲームの概要と背景

1632年11月、リュッツェンでスウェーデン王グスタフ・アドルフが戦死した。プレイヤーは後見政府を率いる国家宰相アクセル・オクセンシェルナとなり、1633年から1644年までの12年間、ドイツでの戦争の継続と国家の運営を担う。ソロ専用で、相手はシステム（皇帝側の軍と、財政・政情の圧力）が務める。

本作はヘックス戦術級の既存2作とは別系統で、簡略エリアマップ（ポイント・トゥ・ポイント）と意思決定フェイズを組み合わせたハイブリッドである。第1部は1644年（クリスティーナ女王の親政開始）までで、結果は第2部への引き継ぎ用に保存される。

## 2. 勝利条件と敗北条件

- **最終評価**：1644年の年末を乗り切れば第1部は終了し、第10章の式で総合評価（スコアとランク）が出る。
- **敗北（即時終了）**：次のいずれかに陥ると、その時点で敗北となる。
  - **失脚**：評議会の信任が0になる。
  - **国内の崩壊**：民心が0になる。
  - **軍の壊滅**：年末時点でスウェーデン側の軍が1つも残っていない。
  - **財政破綻**：年末時点で国庫が0以下（マイナス含む）の年が2年続く。

## 3. ターンとフェイズ

年ターン×12（1633–1644年）。各ターンは次の順に進む。

1. **歳入・報告フェイズ**：増援の到着、歳入の加算、将軍たちからの報告の提示、その年の史実イベント（開始時）の提示。
2. **意思決定フェイズ**：資金配分・方針指令・外交／国内政策アクションを決め、「決定を確定し、戦争を解決する」を押す。
3. **戦争解決フェイズ**：自軍の移動、皇帝側の行動、会戦、占領、皇帝側の回復が自動で解決される。
4. **イベント・年末フェイズ**：政情トラックの変動、史実イベント（年末）とランダムイベントの提示。敗北判定の後、翌年へ進む（1644年は最終評価）。

## 4. 資源と政情トラック

### 国庫と歳入

通貨は抽象単位「金」。開始時の国庫は **30**。毎年の歳入は次の合計（同盟維持費のみ差し引く）。

| 項目 | 額 | 備考 |
|---|---|---|
| 本国税収 | 12＋修正 | 王領地売却1回につき恒常的に−2 |
| 関税・銅 | 5＋修正 | 銅価格イベントで翌年のみ±される |
| フランス補助金 | 基本4＋加算0–4 | コンピエーニュ条約で基本が7になる。交渉で加算を増やせる |
| 分担金 | エリアごと | スウェーデン支配＝満額、同盟エリア＝半額（切り捨て）。ハイルブロン同盟があれば同盟エリア+1 |
| ハイルブロン同盟維持費 | −3 | 同盟を結成した場合のみ、毎年差し引く |

### 政情トラック（各0–100）

| トラック | 初期値 | 主な増減 |
|---|---|---|
| 評議会の信任 | 70 | 年末に−1（国庫20以上なら+1）。会戦の勝利+2／敗北−3（その年の合計）。工作・イベントで変動 |
| 民心 | 60 | 年末に−2。増税−8、負担緩和+9、本国での現地調達−3など |
| 諸侯の結束 | 55 | 年末に−3。同盟地での現地調達−3、譲歩+10、プラハ条約−15など |
| 威信 | 0（上限なし、評価では10まで） | 会戦の勝利ごとに+1。有名な勝利やイベントで加算 |

## 7. 意思決定

### 資金配分と給養

各軍への配分は国庫の範囲内で自由に決める（初期表示は維持費どおり）。維持費は原則 **戦力×1**（本国帰還は半額、現地調達は0）。確定時の効果は配分率（配分÷維持費）で決まる。

| 配分率 | 効果 |
|---|---|
| 1.0以上 | 給養+1（最大3）。超過分は2ごとに補充+1戦力（上限まで） |
| 0.5–1.0未満 | 変化なし |
| 0.5未満 | 給養−1。給養が0になったら戦力−2（飢えと脱走。戦力が尽きれば軍は解散） |

本国帰還は、維持費を全額払えば給養+2・戦力+1の回復が加わる。

### 方針指令

| 方針 | 内容 |
|---|---|
| 進撃 | 指定した隣接エリアへ移動する（疾風の将軍は、敵軍のいないエリアを経由して2エリア先まで可）。デンマークは開戦後のみ |
| 防衛 | その場に留まる。会戦で防御側になったとき自軍の実効戦力+2 |
| 現地調達 | その場に留まり、資金を必要としない。給養は維持されるが、同盟エリアでは結束−3、支配下のドイツでは結束−1、本国では民心−3。会戦では実効戦力−1 |
| 本国帰還 | 本国へ向けて最大2エリア移動する（敵軍のいるエリアには入らない）。回復効果は上記 |

### 外交・国内政策アクション（意思決定フェイズ中、各条件の範囲で実行）

| アクション | コスト | 効果 | 制限 |
|---|---|---|---|
| 臨時増税 | なし | 国庫+8、民心−8 | 年1回 |
| 王領地の売却 | なし | 国庫+12、本国税収−2（恒常）、信任+3、民心−3 | 通算3回まで |
| 負担緩和 | 6 | 民心+9 | 年1回 |
| 評議会への工作 | 4 | 信任+7 | 年1回 |
| フランスとの交渉 | 4 | 補助金の加算+2（最大+4） | 通算2回まで |
| 諸侯への譲歩 | 5 | 結束+10 | 年1回 |

## 8. 戦争解決

### 皇帝側の行動

皇帝側の各軍は、隣接エリアに攻勢に出るかを攻勢性にもとづいて判断する（隣接する自軍より弱いスウェーデン軍、無防備なスウェーデン／同盟支配エリア、係争地が目標になりやすい）。自エリアに自軍がいれば迎撃する。デンマーク軍は本国を守る。戦わず自領に留まった皇帝側の軍は、年末までに戦力+1回復する（上限まで）。

### 会戦

同じエリアに両軍がいる場合に発生する。その年にエリアへ進入した側が攻撃側（双方進入の場合は進撃したスウェーデン側、どちらも進入していない場合はランダム）。

- **実効戦力**＝ その側の各軍の（戦力＋指揮能力＋給養）の合計 ＋ 1d6
  - 防御側のスウェーデン軍が「防衛」方針なら、その軍に+2。防御側の皇帝軍が攻勢に出ていない場合も+2
  - 現地調達中のスウェーデン軍は−1
  - フランスと条約を結んでいる場合、ライン方面・南ドイツでのスウェーデン側に+1
  - 1634年、南ドイツ・バイエルン・ボヘミアでの皇帝側に+1
- **損害**（実効戦力の差による。勝者は常に戦力−1、引き分けは両軍−1）

| 差 | 敗者の損害 |
|---|---|
| 0（引き分け） | 両軍 −1 |
| 1–2 | −2 |
| 3–5 | −3 |
| 6以上 | −4 |

損害はその側の戦力の大きい軍から順に受ける。戦力が0になった軍は壊滅する。
- **退却と支配**：敗北側の生存軍は隣接エリアへ退却する（自側の支配地を優先し、退却先がなければ追加で戦力−1）。敗北側がエリアからいなくなり勝者が残れば、支配が勝者へ移る（同盟エリアをスウェーデン側が防衛・奪回した場合は同盟に戻る）。
- **無抵抗の占領**：会戦の後、一方の軍だけが残ったエリアは、その側の支配に移る（皇帝側／係争→スウェーデン、スウェーデン／同盟／係争→皇帝側）。
- 会戦の勝利は威信+1、信任への影響は勝利+2／敗北−3（年末にまとめて反映）。

### 特殊ルール

- **ホルンの捕虜**：1634年にホルンが会戦に敗れて戦力2以下になると、ネルドリンゲンの史実どおり捕虜となり、軍は失われる（信任−3）。
- **デンマーク戦の決着**：デンマークで会戦に勝つか、デンマーク軍のいないデンマークに軍を置くと、デンマークは屈服する（国庫+8、威信+2、デンマークはスウェーデン支配）。
- **有名な勝利**：条件を満たすと追加の効果がある。
  - ヴィットシュトック（1636年、バネールがブランデンブルク／ヴェストファーレン／ポンメルンで勝利）：結束+8、信任+6、威信+2
  - ケムニッツ（1639年、バネールがザクセン／ボヘミア／ブランデンブルクで勝利）：信任+4、威信+1
  - 第二次ブライテンフェルト（1642年、トルステンソンがザクセン／ボヘミアで勝利）：信任+5、威信+2

### ランダムイベント

年末に55%の確率で1件（同じイベントは1ゲームに1回まで）。凶作、銅価格の変動、凱旋の報せ（その年に会戦で勝った場合のみ）、疫病、フランスの督促、諸侯離反の噂、農民の陳情、敵将の病死がある。

## 11. サウンドと操作

- 操作はタップ／クリックのみ。マップのエリアをタップすると方面情報が表示される。
- 効果音は Web Audio による手続き的合成（外部素材なし）。ヘッダのボタンと開始画面のチェックボックスでオン／オフを切り替え、設定は保存される。
- 「最初から」ボタンと終了画面の「もう一度」は、ページを再読み込みして新規ゲームを始める。
