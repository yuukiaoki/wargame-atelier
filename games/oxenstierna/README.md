# 宰相 — オクセンシェルナと三十年戦争（第1部 1633–44）

グスタフ・アドルフの死（1632年11月）からクリスティーナ女王の親政開始（1644年）まで、国家宰相アクセル・オクセンシェルナとしてスウェーデンの戦争と内政を運営する、ソロ専用の意思決定ゲーム試作です。ルールの詳細は [RULEBOOK.md](RULEBOOK.md)、設計の経緯は [DESIGN.md](DESIGN.md) を参照してください。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（静的サイト、サーバ不要）。毎年、将軍たちへの資金配分と方針（進撃／防衛／現地調達／本国帰還）を決め、外交・国内政策を選んで戦争を解決します。タップ／クリック優先のUIで、スマホでもプレイできます。

## システムの要点

- **ハイブリッド形式**：10エリアの簡略マップ（ポイント・トゥ・ポイント）＋意思決定フェイズ。既存2作（桶狭間、三十年戦争1630）のヘックス・エンジンとは別系統の新エンジン。
- **内政と軍事の葛藤が核**：戦争の金は、本国税収・関税と銅・フランス補助金・ドイツの分担金から得る。本国に課せば民心が、現地調達を強いれば諸侯の結束が、王領地を売れば将来の収入が、補助金を当てにすればフランスへの義理が、それぞれ削られていく。
- **敗北は戦場より先に帳簿と政情で来る**：財政破綻（国庫0以下が2年）、軍の壊滅、信任喪失による失脚、民心の崩壊が敗北条件。
- **史実イベントが背骨**：ハイルブロン同盟（1633）、ネルドリンゲンの危機とホルンの捕虜（1634）、プラハ条約とザクセン離反・フランス参戦（1635）、ポンメルン継承問題（1637）、バネールの死と後任人事（1641）、デンマーク問題（1643）、親政開始（1644）。ヴィットシュトック、ケムニッツ、第二次ブライテンフェルトは、条件を満たせば「有名な勝利」として再現される。
- **評価と引き継ぎ**：1644年末に領土・財政・軍・信任などから総合評価と講評（史実との比較つき）が出る。結果は localStorage に保存され、第2部（1644–48）への引き継ぎデータになる。

## 設計ノート

### 典拠と抽象化

- 史実の骨格（後見政府の財政構造、分担金制度、フランス補助金、王領地の売却・質入れが進んだこと、各年の事件と将軍の動向）は、一般的な三十年戦争史と、翻訳プロジェクトで扱っている Odhner『クリスティーナ女王後見期のスウェーデン内政史』（1865）等の記述に基づく要約レベルの事実関係です。翻訳文そのものは含みません。
- エリア・戦力・金額・確率はすべてゲーム用に自前で設定した抽象化です。1戦力は数千人規模の野戦軍、1金は年予算の大きな塊とお考えください。
- 将軍の能力や性格（バネールの積極性、トルステンソンの疾風、ホルンの運命）は、史実の評価をゲーム向けに単純化したものです。

### ルールの由来と自前設計の範囲

- 「宰相として資源配分と人事・外交を決め、戦争は抽象解決する」という形式は、政治・経営シミュレーションのジャンル慣行に学んだもので、特定の先行作のルールや数値を転写したものではありません。会戦の実効戦力式・損害表・評価式などの具体的な数値と実装はすべて本作独自の設計です。
- 効果音エンジン（js/sound.js）は本リポジトリ第1作「桶狭間 1560」のものを再利用しています（Web Audio による手続き的合成、外部素材なし）。

### 検証（ヘッドレス）

- コアロジックは DOM 非依存に分離してあり、自動方針で通しプレイを検証しました（計100ゲーム、例外なし）。
  - 簡易方針（史実寄りの選択肢＋能動的な資金配分・進撃）：40戦全てが1644年の評価に到達。スコアは53–98点（平均75.4）に分布。
  - ランダムなイベント選択：40戦全てが評価に到達。スコア56–93点。
  - 消極方針（全軍防衛・進撃なし）：20戦中15戦が「軍の壊滅」で敗北し、到達しても34–45点。守り一辺倒では崩れる設計になっています。
- 最小DOMスタブによるUIスモークテストでも、開始→イベント選択→意思決定→終了画面まで例外なく通ることを確認しました。

### 既知の制限（試作版）

- バランスは試作段階です。能動的に打って出る方針では敗北は稀で、競るのはスコアの高低です。難易度（皇帝側AIの攻勢性、歳入の締め具合）の調整は今後の課題です。
- 第二次ブライテンフェルトのような「有名な勝利」は再現条件が限定的で、自動方針ではあまり発生しません（ヴィットシュトックは約半数で発生）。
- 皇帝側AIは簡易なヒューリスティクス（好機への攻勢・自領での回復）で、読みの深さはありません。
- 実機（スマホ）での見た目・操作感は未確認です。マップの軍チップの文字は小さめです。
- 第2部（1644–48）は未実装です。今回は引き継ぎデータの保存までで、第2部の単独プレイ可否も含め設計は DESIGN.md の未決定事項に残してあります。
