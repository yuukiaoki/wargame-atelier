# 桶狭間 1560 — ヘックスウォーゲーム試作

HEX（ヘックスグリッド）＋素の JavaScript で作った、ブラウザで遊べる戦術級ウォーゲームの試作です。サーバ不要の静的サイトです。

## 遊び方

1. `index.html` をブラウザで開く（または GitHub Pages の URL にアクセス）。
2. 指揮する軍（織田軍＝赤／今川軍＝紺）と史観モードを選んで開始。選ばなかった軍は AI が指揮する。
3. 自軍ユニットをタップ → 光ったヘックスへ移動 → 敵に隣接していれば敵をタップして攻撃。
4. 「フェイズ終了」で相手フェイズへ。全8ターン。
5. 今川義元本陣ユニットを壊滅させれば織田軍の勝利。信長本隊が壊滅するか、8ターン守り切られると今川軍の勝利。
6. 今川軍でプレイする場合、本陣の「油断／警戒」は自軍の状態として機能する。序盤は油断（本陣・警固の防御-2）のまま織田軍の接近を迎えることになる。

## ルールの要点

- 移動：地形コスト制（街道1／平地・砦・城2／丘陵・林3／狭間4）。敵の支配地域（ZOC）に入ると追加コスト＋その場で停止。
- 戦闘：戦力比による戦闘結果表（CRT）を1d6で解決。損害（戦力減少）と退却。
- 防御ボーナス：丘陵・林・狭間・砦/城は防御側に戦力+1。
- 今川本陣の「油断／警戒」：本陣と警固隊は油断状態（防御-2）で開始。織田軍の接近・本陣への攻撃・第5ターン経過で警戒に移る。
- 史観モード（論点の両論併記をルール化）：
  - 通説モード：第4ターンに豪雨。今川軍はそのターン防御-2、警戒判定の距離も短くなる（豪雨の奇襲）。
  - 正面攻撃モード：豪雨なし。本陣は最初から警戒。織田軍は丘陵（太子ヶ根側）から攻撃すると戦力+1（正面攻撃説）。

## 公開

このゲームは wargame-atelier リポジトリの一部として GitHub Pages で公開されます（手順はリポジトリのルート README を参照）。単体では `index.html` をブラウザで開けば遊べます。

## 設計ノート（典拠と論点）

- 基礎事実の典拠は japan-military-biographies リポジトリの wars/okehazama（『信長公記』『三河物語』等の一次史料と研究書）。本ゲームのシナリオデータは要約レベルの事実関係のみで構成し、翻訳文そのものは含まない。
- 兵力：今川軍総勢約2万5千（諸説あり）に対し本陣攻撃の織田軍は約2千〜3千。今川軍は分散していたため、本シナリオではマップ上の今川軍も各地に分散配置し、本陣周辺は警固隊のみとした。
- 論点「奇襲か正面攻撃か」：『信長公記』に奇襲の明記はなく、藤本正行らは正面攻撃で決着したと説く。豪雨の奇襲の物語は江戸時代の軍記（『甫庵信長記』系）に由来するとされる。本ゲームでは両説をモードとして併記した。
- 田楽狭間の位置（名古屋市緑区／豊明市）には両説があり、マップは様式化したもので実地形の確定再現ではない。
- ユニット編成・指揮官名・戦力値はゲーム上の抽象化である（当時の部隊編成をそのまま再現したものではない）。

## 構成

- `index.html` … 画面と開始／終了オーバーレイ
- `css/style.css` … スタイル
- `js/scenario.js` … マップ・ユニット・地形のシナリオデータ（差し替えれば別シナリオになる）
- `js/game.js` … エンジン（移動・戦闘・AI・描画）
