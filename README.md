# ウォーゲーム工房（wargame-atelier）

史料から戦術モデルを抽出してヘックスグリッド上で再現する、ブラウザで遊べるウォーゲーム集です。HEX＋素の JavaScript、サーバ不要の静的サイトで、GitHub Pages で公開します。

## 収録ゲーム

| ゲーム | 状態 | 概要 |
|---|---|---|
| [桶狭間 1560](games/okehazama-1560/) | 試作・プレイ可 | 信長が今川義元本陣を狙う戦術級。奇襲説／正面攻撃説をモード化 |
| ポワティエ 1356 | 構想中 | 黒太子対フランス軍。底本確保から |
| ケーニヒグレーツ 1866 | 構想中 | 普墺戦争の決戦。Wagner 全訳が典拠 |

## 構成

- `index.html` … ポータル（ゲーム一覧）
- `games/<game>/` … ゲームごとに自己完結（`index.html` / `css/` / `js/scenario.js` シナリオデータ / `js/game.js` エンジン）
- `shared/` … 共通部品置き場（2本目の追加時にヘックス処理等を抽出する予定）

新しいゲームは `games/` にフォルダを足し、ポータルの `index.html` にリンクを1件追加するだけです。

## GitHub Pages での公開

1. このリポジトリをパブリックで作成する。
2. Settings → Pages → Build and deployment で Source に「Deploy from a branch」、Branch に `main` / `/ (root)` を選ぶ。
3. 数分で `https://yuukiaoki.github.io/wargame-atelier/` がポータルとして公開され、各ゲームはその下のパスで遊べる。

## 設計方針

- 各ゲームのシナリオデータは、典拠に基づく要約レベルの事実関係のみで構成し、翻訳文そのものは含まない。
- 史学上の論点がある場合は両論を併記し、可能なものはルールのモードとして実装する（例：桶狭間の奇襲説／正面攻撃説）。
- ユニット編成・戦力値はゲーム上の抽象化であり、その旨を各ゲームの設計ノートに明記する。
